# Health-O-Tech Website Development Guide

This skill provides architecture guidelines, styling conventions, and animation best practices for the Health-O-Tech (HOT) website.

---

## 1. Tech Stack & Architecture

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`) with custom biopunk theme CSS variables in `src/index.css`
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Backend / Data Layer**: Google Drive & Sheets Live Sync API (Google Apps Script Web App)
- **Routing**: React Router DOM (`/` for Home, `/team` for Team Hierarchy)

## 2. Animation & Framer Motion Rules (Critical)

To prevent visual glitches, double-loading stutters, and layout snapping:

### A. Never Mix CSS `transition-all` with Framer Motion Transforms
- **Rule**: Do **NOT** apply Tailwind's `transition-all` or `transition-all duration-300` to any `motion.div` that animates `transform`, `opacity`, or `layout`.
- **Reason**: The browser's CSS transition engine intercepts every frame generated by Framer Motion, creating a stuttering two-step animation that appears to reload or animate twice.
- **Correct Pattern**:
  ```jsx
  // Good: Only transition border & shadow for hover states
  <motion.div
    variants={cardVariants}
    className="rounded-2xl bg-[var(--surface-card)] border border-[var(--border-accent)] hover:border-[var(--accent-cyan)] transition-[border-color,box-shadow] duration-200"
  >
  ```

### B. Use Unified Container Stagger (Not Per-Card Observers)
- **Rule**: Orchestrate card grid entrances using `containerVariants` with `staggerChildren` on the parent grid, with a single `whileInView` trigger.
- **Correct Pattern**:
  ```jsx
  const containerVariants = {
    hidden: { opacity: 0 },
    visible: {
      opacity: 1,
      transition: { staggerChildren: 0.08, delayChildren: 0.1 },
    },
  };

  const cardVariants = {
    hidden: { opacity: 0, y: 24 },
    visible: { opacity: 1, y: 0, transition: { duration: 0.45, ease: [0.25, 1, 0.5, 1] } },
  };

  <motion.div
    variants={containerVariants}
    initial="hidden"
    whileInView="visible"
    viewport={{ once: true, amount: 0.15 }}
    className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6"
  >
    {items.map(item => <motion.div key={item.id} variants={cardVariants} />)}
  </motion.div>
  ```

### C. Smooth Filter Grid Animations with `mode="popLayout"`
- When filtering lists (e.g., in `ProjectsSection.jsx`), always use `mode="popLayout"` on `<AnimatePresence>`:
  ```jsx
  <AnimatePresence mode="popLayout">
    {filteredItems.map(item => (
      <motion.div
        key={item.id}
        layout
        initial={{ opacity: 0, scale: 0.95 }}
        animate={{ opacity: 1, scale: 1 }}
        exit={{ opacity: 0, scale: 0.95 }}
        transition={{ duration: 0.28, ease: 'easeOut' }}
      />
    ))}
  </AnimatePresence>
  ```
- **Never add artificial index delays** (`delay: idx * 0.1`) to layout-shifting cards during filtering.

### D. Avoid Nested `whileInView`
- If an outer container already animates in with `whileInView`, internal child cards or list items should rely on parent variants or standard CSS transitions rather than registering independent nested intersection observers.

## 3. Cyber Biopunk Design System

Defined in `src/index.css`:
- **Background**: `--bg: #090717` (Deep Space Dark)
- **Surfaces**: `--surface: #130F29`, `--surface-card: rgba(19, 15, 41, 0.75)`
- **Accents**:
  - Cyan: `--accent-cyan: #00C8FF` (Technology & Diagnostics)
  - Green: `--accent-green: #00E676` (Biology & Life Sciences)
  - Purple: `--accent-purple: #A855F7` (Genomics & R&D)
- **Typography**:
  - Headings: `font-orbitron` (`'Orbitron', sans-serif`)
  - Body & UI: `font-space` (`'Space Grotesk', sans-serif`)
- **Glow Classes**: `.glow-text-cyan`, `.glow-text-green`, `.glow-cyan`

---

## 4. Form Control Guidelines

When adding inputs or text areas:
- Use clean dark background: `bg-[#0d0922]/90` with `shadow-inner`.
- Contrast placeholders: `placeholder:text-neutral-500`.
- Focus glow ring: `focus:outline-none focus:border-[var(--accent-cyan)] focus:ring-2 focus:ring-[var(--accent-cyan)]/25`.
- Custom select dropdown: Wrap in a relative container with `appearance-none` and embed `ChevronDown` from `lucide-react` with `pointer-events-none`.
